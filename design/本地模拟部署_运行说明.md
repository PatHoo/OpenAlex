# WSL 本地模拟云端部署（nginx + sharecode 门禁）

在 WSL 里用**真 nginx** 复刻云端访问链路，本地验证通过后再上云。
访问地址：**http://127.0.0.1:8080**　测试分享码：**`LocalTest2026`**

> **两个页面的区别（别搞混）**
> - 根路径 `/` = **第一期的「学者作品自助抓取工具」**（公开、无需登录）。
> - `/web/index.html` = **第二期科研分析平台 DEMO**（受门禁保护）——含统计分析、空间流向、
>   学者轨迹、DID、中国背景证据、文献模块、本地软件协同、客户认可维度、导出共 9 个页签。
>   从根路径页面右上角的「进入第二期 DEMO →」按钮可一键跳转（本地 nginx sub_filter 注入，
>   仅本地模拟有，线上不注入）。要测二期 DEMO，请走这个入口。

## 1. 架构（与云端逐项对照）

| 环节 | 云端 | 本地模拟 |
|---|---|---|
| Web 服务 | nginx 443 + Let's Encrypt | nginx 8080，HTTP（无证书） |
| 站点根 | `/var/www/openalex` | `/var/www/openalex`（一致） |
| 门禁 | `gate_service.py` :8765，COS/CDN 签名下载 | `local_gate_service.py` :8765，直出本地文件 |
| Cookie | HttpOnly + Secure | HttpOnly，无 Secure（HTTP 必需） |
| 地图 Key | nginx `sub_filter` 注入真实 Key | 同机制，注入 `LOCAL-SIM-KEY-DO-NOT-USE` |
| 数据库 | PostgreSQL 17 在云端，客户浏览不查库 | 未启动（本模拟只验证浏览/门禁链路） |

sharecode 校验算法与生产版完全相同（HMAC-SHA256，Cookie 只放摘要不放明文）。

## 2. 一键启停（在 WSL 里执行）

```bash
# 启动：自动起门禁 8765 + nginx 8080
~/openalex-sim/start_local_sim.sh

# 停止
~/openalex-sim/stop_local_sim.sh

# 端到端验证（9 项，应全 PASS）
~/openalex-sim/verify_local_sim.sh
```

`start_local_sim.sh` 会调用 `wsl.exe -u root ~/openalex-sim/install_nginx.sh` 安装站点配置，
所以从 Windows 侧执行 `wsl -e bash -lc '~/openalex-sim/start_local_sim.sh'` 也可。

## 3. 手动测试流程

1. 打开 http://127.0.0.1:8080/ —— 公开的自助抓取工具页，无需登录。
2. 访问 http://127.0.0.1:8080/web/index.html —— 应 302 跳到 `/login?next=...`。
3. 在地址栏输入 `http://127.0.0.1:8080/login?sharecode=wrong` —— 应 403。
4. 输入 `http://127.0.0.1:8080/login?sharecode=LocalTest2026&next=/web/index.html`
   —— 302 回平台页并种下 Cookie，页面正常显示 26-sheet 工作簿入口与图表。
5. 点“客户认可维度工作簿”下的 Excel 下载 —— 应直接下载（门禁鉴权后直出文件）。
6. 地图区域显示 `LOCAL-SIM-KEY-DO-NOT-USE` 已注入（前端占位符被 nginx 替换），
   因是假 Key，实际地图瓦片不会加载；上云换成真实 Key 即可。
7. 访问 `http://127.0.0.1:8080/logout` 清 Cookie，再访问 `/web/` 应重新跳登录。

## 4. 文件位置

- 运行目录：`~/openalex-sim/`（gate.env、脚本、日志、PID）
- 站点：`~/openalex-sim/www/` → 安装时同步到 `/var/www/openalex/`
- 门禁：`~/openalex-sim/bin/local_gate_service.py`
- nginx 配置源：`design/deploy_assets/nginx-local-sim.conf`
- nginx 生效配置：`/etc/nginx/sites-enabled/openalex-local`

## 5. 与云端的差异（上云时要改回）

1. **HTTPS**：本地 8080 HTTP；云端 443 + certbot，Cookie 带 `Secure`。
2. **下载**：本地门禁直出 `/var/www/openalex/web/download/*.xlsx`；
   云端用 `gate_service.py` 生成 COS V5 签名 URL 并 302 到 CDN（CDN 缓存键需忽略 `q-sign-*`）。
3. **地图 Key**：本地 `gate.env` 的 `TMAP_KEY` 假值；云端用真实腾讯位置服务 Key，
   且由 nginx `sub_filter` 注入，不写进前端仓库。
4. **分享码**：本地 `LocalTest2026`；云端用 `secrets.token_urlsafe(32)` 生成并放 `/etc/openalex/gate.env`。
5. **数据库**：本地未起 PostgreSQL；云端按 `云主机部署清单_nginx_CDN.md` 第 4 节恢复 2.1 GB 转储。
   客户浏览路径不查库，所以不影响本模拟的验证结论。

## 6.  reinstall / 重置

```bash
wsl -e bash -lc '~/openalex-sim/setup_local_sim.sh'   # 重建 ~/openalex-sim（会清日志与 PID）
wsl -u root -e bash -lc '~/openalex-sim/install_nginx.sh'  # 重装 nginx 站点
~/openalex-sim/start_local_sim.sh
```
