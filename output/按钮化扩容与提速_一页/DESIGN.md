# DESIGN.md — 按钮化扩容 + 付费提速（一页整合版）

## 页面定位
把客户最关心的两件事压进一页：**① 点按钮后发生什么（触发链路）② 同一套按钮两种速度（付费提速）**。
口径锚点：按钮只负责「触发 + 看进度」，跑批逻辑一行不改；付费只决定快慢，不改变流程。

## 全局视觉约定（沿用付费提速一页版，保证系列一致）
### ① 画布与安全区
- 画布 1280×720，padding 60，内容区 1160×600（x 60–1220，y 60–660）
- 页尾顶边 y=670，字号 14px，固定左下/右下

### ② 配色方案
- 主色：`#12324F`（深藏蓝，标题/编号/顶条）
- 辅色：`#E9F1F8`（浅蓝灰，卡片底/分隔线）
- 强调色：`#E07B39`（暖橙，关键数字）
- 语义色：推荐档 `#0F766E` 青绿描边/浅底；提醒 `#C2410C` 橙红
- 底色 `#FFFFFF`；正文 `#1E293B`；辅助 `#64748B`

### ③ 字体系统
- 中文 Microsoft YaHei；西文 Arial
- 字号阶梯：主标 32 / 副标 19 / 区块小标 20 / 流程步标 17 / 流程说明 15 / 对比行 18 / 数字锚点 40 / 提醒 16 / 脚注 14

### ④ 视觉母题
- 主标题下 1px 贯通细线（x60→x1220）
- 上下两区各带小标题；中间用一条贯通分隔线
- 页脚左「OpenAlex 科研分析平台 · 商务沟通稿」/ 右「来源：help.openalex.org · 核实 2026-11-25」

### ⑤ 配图清单
- 无配图。结论由流程步骤与对比数字承担。

## 逐页字段
- title: 一键扩容到 5,000 人：点按钮之后发生什么
- type: content
- role: summary
- rhythm: steady
- layout: 顶部主标题+副标 → 上半「四步触发链路」横向流程 → 中部贯通分隔 → 下半「同一套按钮两种速度」三档对比 → 底部提醒条（主 key + 三组待拍板）
- density: 字数约 300 / 图片 0 / 留白约 18%
- anti_pattern: 禁止三等分卡片横排；禁止流程步骤塞进窄框；禁止无数字托底的形容词；禁止把待拍板问题做成大表格
- description: 用四步流程讲清按钮是后台任务不是即时计算；用三档对比（免费 5 天/预付 $10 约 1.5-3 小时/年付过剩）承接提速诉求；底部提醒账户主 key 与三组待客户拍板问题（谁能点/钱谁出/等待期怎么展示）。
