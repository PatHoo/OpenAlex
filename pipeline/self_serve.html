学者作品自助抓取工具

基于 OpenAlex 公开 API。您自己申请 key、自己抓取，数据与额度都归您，工具只固定抓取方式和路径。

① 设置 OpenAlex API Key

免费 key 每天 $1 额度（约 1 万次检索请求）、30 请求/秒。 去 openalex.org/signup 注册， 再到 设置页 复制 key，并到邮箱点激活链接。

② 选择学者名单

预置名单按 Elsevier 2017 高被引排名升序（引用最高者优先）。
